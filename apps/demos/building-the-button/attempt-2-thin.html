Size axis (the button's second axis) — rest state, current density

Heights are never authored: they emerge from inset x 2 + cap per size and density. At comfortable density: sm = 24px, md = 36px — one density step apart, same recipe. Switch the density toggle above to watch every number here recompute (compact: 20/24, relaxed: 36/44).

Leading icon + label (icon-gap and icon ink together)

Icon gap is derived from the label, never the ladder: round(fontSize x 0.618, 2px) — 8px here at comfortable/md. The glyph's footprint is the label's cap box; its ink overflows via a negative margin, exactly like an ascender.

Font stack: Inter, system-ui, -apple-system, "Segoe UI", Roboto, Helvetica, Arial, sans-serif — Inter named first per DESIGN.md typography.body.fontFamily, no network fetch, system fallback if Inter isn't installed locally.
